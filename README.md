# Конвертер валют

Локальное приложение из четырёх контейнеров: фронтенд на HTML/CSS/JS с nginx,
бекенд на ASP.NET Core 10, PostgreSQL и отдельный сервис курсов. Данные о валютах
и курсах поступают из [Frankfurter](https://frankfurter.dev/); API-ключ не нужен.
Список включает доступные действующие денежные валюты, в том числе RUB и GEL.
Флажки хранятся в проекте; SVG взяты из [flag-icons](https://github.com/lipis/flag-icons)
под лицензией MIT (`frontend/flags/LICENSE`).

Введите сумму в любой валютной строке — остальные строки пересчитаются сразу.
Нужную валюту можно найти по коду, русскому или английскому названию и добавить
из результатов поиска. Одновременно доступно до десяти валют; их можно убирать.
Кнопка «Сохранить расчёт» записывает результаты для всех показанных пар в PostgreSQL. Кнопка
«Показать историю» загружает сохранённые записи из базы; их можно удалять.

## Запуск

Откройте PowerShell в корне проекта и выполните:

```powershell
docker compose up --build -d
```

Откройте [http://localhost:8080](http://localhost:8080).
Для остановки:

```powershell
docker compose down
```

Локальные настройки PostgreSQL уже заданы: пользователь `currency_app`, пароль
`currency_local_2026`. При желании скопируйте `.env.example` в `.env` и измените
пароль или порты. `.env` исключён из Git. Если том PostgreSQL ранее был создан
с другим паролем, смена переменной окружения не изменит пароль в существующей БД.

PostgreSQL хранит историю в Docker volume `postgres_data`. EF Core автоматически
применяет миграции. Курсы справочные: денежный обмен приложение не выполняет.

Методы бекенда описаны в [`backend/README.md`](backend/README.md), сервис курсов —
в [`web-service/README.md`](web-service/README.md).

Проверка обработки ответа Frankfurter без сетевого запроса:

```powershell
dotnet run --project tests/MarketSmoke/MarketSmoke.csproj
```
